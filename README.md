## Requirements

- Python 3.11

## Installation

Install the required dependencies:
```bash
pip install -r requirements.txt
```
After installing the dependencies, run the BasicSR compatibility patch:
```bash
python patch_basicsr.py
```

## Usage

1. Create a folder named "input" in the project root directory.

2. Place your input image inside the "input" folder and name it "photo.jpg".

3. Run the program:
   ```bash
   python main.py
   ```
The enhanced image will be automatically saved in the "enhanced" folder as "photo_4x.png".
